## What this benchmark does NOT measure

- **Layer 3 (Citation):** actual LLM citations in answers from ChatGPT / Claude / Perplexity / Gemini. Run `scripts/aeo-citation-test.mjs` for that — needs Chrome MCP browser automation.
- **Inbound backlink count:** would need paid Ahrefs/Moz/SEMrush. Wikipedia + domain age + GitHub stars are free proxies.
- **Content freshness:** how often the site publishes new long-form content. Worth adding in v3.
- **Brand mentions in news:** Google News doesn't expose a free API. Could add via NewsAPI free tier (100 req/day).

A site that wins Layers 1+2 has **the technical and authority foundation** to be cited by AI engines. Whether it IS being cited is Layer 3 — a separate measurement.
